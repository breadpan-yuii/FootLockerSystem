# Foot Locker PH — Student Project

A small e-commerce web application built with Laravel. It includes a customer storefront
(browse, search, cart, checkout, order tracking, wishlist) and an admin panel
(products, categories, brands, customers, orders).

> **Disclaimer:** This is an educational student project. It is **not affiliated with,
> endorsed by, or connected to Foot Locker, Inc.** or any of the brands shown. All product
> names and images are used for demonstration only. Do not deploy this publicly.

---

## Features

**Storefront**
- Home page with featured products, brand tiles and category tiles
- Shop with search, category/brand/gender filters, price range and sorting
- Product detail pages with image gallery, size/variant selection and stock status
- Shopping cart (quantity updates, remove items)
- Checkout (delivery details, payment method selection)
- Order tracking by order number
- Wishlist (add/remove)
- Customer accounts: register, login, profile management

**Admin panel** (`/admin`, role-restricted)
- Dashboard with store statistics
- Products CRUD (with images and variants)
- Categories and brands CRUD
- Customer list and detail views
- Orders list, detail view and status updates

## Installation

1. **Install PHP dependencies**

   ```sh
   composer install
   ```

2. **Create the environment file and application key**

   ```sh
   cp .env.example .env
   php artisan key:generate
   ```

3. **Create the database**

   ```sh
   mysql -u root -p -e "CREATE DATABASE footlocker_system CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
   ```

4. **Configure the database** — edit `.env` and set `DB_USERNAME` / `DB_PASSWORD` to match
   your MySQL setup (see [Environment configuration](#environment-configuration)).

5. **Run migrations and seed the database**

   ```sh
   php artisan migrate --seed
   ```

6. **Install frontend dependencies and build assets**

   ```sh
   npm install
   npm run build
   ```

7. **Create the storage symlink** (needed for product image uploads from the admin panel)

   ```sh
   php artisan storage:link
   ```

8. **Start the development server**

   ```sh
   php artisan serve
   ```

   The app will be available at <http://localhost:8000>.

### Shortcut

Composer defines a `setup` script that runs most of the above:

```sh
composer setup
```

Note: it runs `migrate` **without** `--seed`, does not create the database, and does not run
`storage:link`. After using it, still run:

```sh
php artisan db:seed
php artisan storage:link
```

## Environment Configuration

The important values in `.env`:

| Key | Notes |
|-----|-------|
| `APP_NAME` | Already set to "Foot Locker" |
| `APP_URL` | `http://localhost:8000` for local development |
| `APP_KEY` | Generated by `php artisan key:generate` — required |
| `DB_CONNECTION` | `mysql` |
| `DB_DATABASE` | `footlocker_system` |
| `DB_USERNAME` | Your MySQL user (typically `root`) |
| `DB_PASSWORD` | Your MySQL password — the example file ships it **blank**; set it to match your server |
| `SESSION_DRIVER` | `database` — requires migrations to have run |
| `CACHE_STORE` | `database` — requires migrations to have run |
| `QUEUE_CONNECTION` | `database` |
| `MAIL_MAILER` | `log` — emails are written to `storage/logs/laravel.log` |

> Because sessions, cache and queues all use the database driver, running `php artisan migrate`
> before using the app is mandatory. Without it, pages will error.

## Business Rules

- **Free shipping** on orders of **₱3,000 and above**; otherwise a flat **₱150** fee.
- **Order numbers** use the format `FL-XXXXXXXX`.
- **Order statuses:** `pending` → `confirmed` → `preparing` → `completed`, plus `cancelled`.
- **Payment methods:** Cash on Delivery, GCash, Bank Transfer (collected manually; no live
  payment gateway is integrated).
- **Roles:** users have a `role` of either `admin` or `customer`. The `admin` middleware
  guards all `/admin` routes.

## Troubleshooting

**The store is empty after setup.**
You ran `migrate` without seeding. Run `php artisan db:seed` (or `php artisan migrate:fresh --seed`).

**Page loads with no styling.**
Frontend assets were not built. Run `npm install && npm run build`, then hard-refresh the browser.

**"No application encryption key has been specified."**
Run `php artisan key:generate`.

**500 errors on any page / login fails immediately.**
Sessions use the database driver. Make sure `php artisan migrate` has run and the `sessions`
table exists.

**Database connection error.**
Confirm MySQL is running, the `footlocker_system` database exists, and `DB_USERNAME` /
`DB_PASSWORD` in `.env` are correct.

**Uploaded images show broken links.**
Run `php artisan storage:link` to create the `public/storage` symlink.

**Config changes not taking effect.**
Clear the caches:

```sh
php artisan optimize:clear
```
