CONCLUSION AND RECOMMENDATIONS

Conclusion. The Foot Locker PH system was successfully developed as a
database-driven e-commerce web application using Laravel. The project
fulfilled its objectives: it provides a complete customer storefront -
browsing, searching, filtering, cart, checkout, order tracking,
wishlist, and account management - and a secured admin/owner panel for
managing products, categories, brands, customers, and orders. All
information is stored in and retrieved from a normalized MySQL database
(Third Normal Form) through Laravel migrations and Eloquent
relationships, so any change made by the administrator is immediately
reflected on the customer-facing website. The system demonstrates the
integration of advanced database design, system architecture, and
advanced web development concepts into one working application.

The ERD and the implemented database are consistent with each other:
entities, attributes, primary keys, foreign keys, relationships, and
cardinality all match the actual migrations. Data integrity is enforced
with primary keys, foreign keys (with cascade rules), unique
constraints, and enumerated fields for controlled values such as role,
gender, and order status.

Recommendations. For future improvement, the following are recommended:
(1) integrate a real online payment gateway (e.g., GCash/PayMongo) to
replace manual and Cash-on-Delivery payment; (2) add email or SMS
notifications for order confirmation and status changes; (3) implement
product reviews and ratings from verified buyers; (4) add low-stock
alerts and automated stock reports for the admin; (5) introduce sales
analytics with exportable reports (PDF/Excel) on the admin dashboard;
(6) add multi-image upload with drag-and-drop and image optimization;
(7) implement discount codes and promo management; (8) add automated
tests and continuous integration for reliability; (9) deploy the system
to a live server with HTTPS and database backups; and (10) improve
accessibility and mobile responsiveness further.
