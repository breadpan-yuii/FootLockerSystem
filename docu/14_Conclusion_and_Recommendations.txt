14 - CONCLUSION AND RECOMMENDATIONS

CONCLUSION
----------
The Foot Locker PH system was successfully developed as a database-driven
e-commerce web application using Laravel. The project fulfilled its
objectives: it provided a complete customer storefront - browsing,
searching, filtering, cart, checkout, order tracking, wishlist, and account
management - and a secured admin/owner panel for managing products,
categories, brands, customers, and orders. All information is stored in
and retrieved from a normalized MySQL database (Third Normal Form) through
Laravel migrations and Eloquent relationships, so any change made by the
administrator is immediately reflected on the customer-facing website. The
system demonstrates the integration of advanced database design, system
architecture, and advanced web development concepts into one working
application.

The ERD and the implemented database are consistent with each other:
entities, attributes, primary keys, foreign keys, relationships, and
cardinality all match the actual migrations. Data integrity is enforced
using primary keys, foreign keys (with cascade rules), unique constraints,
and enumerated fields for controlled values such as role, gender, and
order status.

RECOMMENDATIONS
---------------
For future improvement, the following are recommended:

1. Integrate a real online payment gateway (e.g., GCash/PayMongo) to
   replace manual/Cash-on-Delivery payment.
2. Add email or SMS notifications for order confirmation and status
   changes.
3. Implement product reviews and ratings from verified buyers.
4. Add inventory low-stock alerts and automated stock reports for admin.
5. Introduce sales analytics and exportable reports (PDF/Excel) on the
   admin dashboard.
6. Add multi-image upload with drag-and-drop and image optimization.
7. Implement discount codes / promo management.
8. Add automated tests and continuous integration for reliability.
9. Deploy the system to a live server with HTTPS and database backups.
10. Improve accessibility and mobile responsiveness further.
