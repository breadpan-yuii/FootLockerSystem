15 - FORMATTING SPECS (from Docu_Template.docx)
========================================================================
Apply ALL of the following in Microsoft Word or Google Docs.

FONT            : Times New Roman
FONT SIZE       : 12 pt for titles
                  11 pt for content/body
LINE SPACING    : 1.5
PARAGRAPH SPACE : Remove "space before" and "space after" paragraphs
                  (set both to 0)
MARGINS         : 1 inch on ALL sides (top, bottom, left, right)
ALIGNMENT       : Justified
PAPER SIZE      : 8.5 x 11 inches (US Letter)

DOCUMENT ORDER (follow the template):
  1. Cover Page
  2. Business / Project Overview
  3. Business Objectives
  4. System Features            (include screenshots)
  5. Data Dictionary
  6. Requirements Modeling
       - Entity Relationship Diagram
       - Functional Decomposition Diagram (Figure: 01)
       - Use Case Diagrams, one per user (Figures: 02a Guest, 02b Customer,
         02c Admin)
       - Activity Diagram (Figure: 03)
       - Sequence Diagrams, split in two (Figures: 04a Add to Cart,
         04b Checkout)
  7. Problems and Solutions
  8. Conclusion and Recommendations

WORD STEPS (quick)
------------------
- Layout tab -> Margins -> Normal (1" all sides).
- Home tab -> select all -> Font: Times New Roman; Size 11.
- Home tab -> Paragraph -> Line spacing: 1.5 -> Before: 0 pt, After: 0 pt
  -> Alignment: Justified -> OK.
- For titles: set size 12 pt and Bold as needed.
- Insert each diagram/screenshot -> right-click -> Wrap Text: In Line With
  Text (keeps layout stable) -> center it if desired.
- Add a caption under each figure (e.g., "Figure 1. Entity Relationship
  Diagram").

REMINDERS
---------
- REMOVE the template's instruction block (the "FOLLOW THIS FORMAT"
  section) before finalizing.
- Keep the college name and instructor names exactly as on the cover page.
- Save as .docx (Word) and/or upload to Google Drive as required.
