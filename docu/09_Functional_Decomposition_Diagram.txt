modules. (Derived from routes/web.php.)

(A) RECOMMENDED TOOLS
------------------------------------------------------------------------
- draw.io / diagrams.net (free) -> hierarchical boxes.
- Lucidchart, Canva, or even PowerPoint SmartArt (hierarchy).

------------------------------------------------------------------------
LEVEL 0 (root):
    FOOT LOCKER PH SYSTEM

LEVEL 1 (two subsystems):
    1.0 Customer / Public Website
    2.0 Admin / Owner Website

LEVEL 2 (modules under each):

1.0 Customer / Public Website

        1.2.3 Sort by Price / Name

        1.3.2 Select Size / Color Variant

        1.4.1 Add to Cart

        1.4.3 Remove Item

    1.7 Customer Account

    2.6 Manage Orders
        2.6.1 View Orders / Order Details
        2.6.2 Update Order Status

------------------------------------------------------------------------
(C) STEP-BY-STEP DRAWING INSTRUCTIONS
------------------------------------------------------------------------
1. Draw a single rectangle at the top: "FOOT LOCKER PH SYSTEM".
2. Draw a horizontal line below it with two branch lines going down.
3. At the ends of those branches, draw two boxes:
   "Customer / Public Website" and "Admin / Owner Website".
4. For each subsystem, branch again to its modules (Level 2 boxes).
5. For Shop, Product Details, Cart, Checkout and Manage Products, branch
   once more into the Level-3 boxes shown above.
6. Optionally number each box (1.0, 1.1, 2.2.1 ...) as shown.
7. Keep boxes aligned; use the same box style throughout.
