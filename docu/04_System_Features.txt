========================================================================
04 - SYSTEM FEATURES
========================================================================
(All screenshots have been captured and are stored in:
  Customer side : docu/screenshots/storefront/
  Admin side    : docu/screenshots/admin/
Every figure below is labeled "Figure N." in the order it appears in this
section. Insert each image directly under its feature with the caption.)

The system has two major parts: the CUSTOMER (public) side and the
OWNER/ADMIN side.

------------------------------------------------------------------------
A. CUSTOMER / PUBLIC SIDE (Storefront)
------------------------------------------------------------------------
1. Home Page
   - Hero banner, featured products, brand tiles, and category tiles.
   [Figure 1: storefront/05_01_home.png - Home Page (hero banner,
    featured products, brand and category tiles)]

2. Shop / Product Catalog
   - Lists all active products.
   - Search by product name/keyword.
   - Filter by category, brand, and gender (men/women/kids/unisex).
   - Filter by price range and sort by price/name.
   [Figure 2: storefront/05_02_shop_filters.png - Shop Page with Filters
    (brand, gender, and sort applied)]
   [Figure 3: storefront/05_03_search.png - Search Results (keyword
    "samba")]

3. Product Detail Page
   - Product name, brand, description, price (with sale price display).
   - Image gallery (primary + additional images).
   - Size/color variant selection with per-variant stock.
   - Stock status and add-to-cart button.
   - Related products.
   [Figure 4: storefront/05_04_product_detail.png - Product Detail Page
    (gallery, size variants, price, stock, add-to-bag, related items)]

4. Shopping Cart
   - Add items to cart, update quantity, remove items.
   - Live subtotal, shipping fee, and total computation.
   [Figure 5: storefront/05_05_cart.png - Shopping Cart (items,
    quantities, subtotal, shipping fee, total)]

5. Checkout
   - Enter/confirm delivery details (full name, phone, address).
   - Choose payment method: Cash on Delivery (default), GCash, or
     Bank Transfer.
   - Add optional order notes.
   - Place order -> creates an order with a unique order number.
   [Figure 6: storefront/05_06_checkout.png - Checkout Page (delivery
    details, payment method, order summary)]
   [Figure 7: storefront/05_07_order_confirmation.png - Order
    Confirmation showing the generated FL-XXXXXXXX order number]

6. Order Tracking
   - Track an order by entering the order number (no login required).
   [Figure 8: storefront/05_08a_track_form.png - Order Tracking Form
    (no login required)]
   [Figure 9: storefront/05_08b_track_result.png - Order Tracking Result
    (returned order status)]

7. Customer Account
   - Registration and login (Laravel Breeze).
   - My Orders: list of the customer's orders and their statuses.
   - Order detail view.
   - Wishlist: add/remove saved products.
   - Profile management (update info, change password, delete account).
   [Figure 10: storefront/05_11a_login.png - Login Page]
   [Figure 11: storefront/05_11b_register.png - Registration Page]
   [Figure 12: storefront/05_09a_my_orders.png - My Orders (list with
    statuses)]
   [Figure 13: storefront/05_09b_order_detail.png - Order Detail View]
   [Figure 14: storefront/05_10_wishlist.png - Wishlist]
   [Figure 15: storefront/05_12_profile.png - Profile Page (update info,
    change password, delete account)]

3. Manage Categories (CRUD)

   [Figure 20: admin/06_04a_categories_list.png - Categories - List]

4. Manage Brands (CRUD)

5. Manage Customers
   - View customer list and individual customer details.

------------------------------------------------------------------------
TECHNOLOGIES USED (Rubric Criterion 8 - include in documentation)
------------------------------------------------------------------------
- Backend: Laravel 13 (PHP 8.3), Eloquent ORM, Laravel Breeze 2.4 (auth:
  register/login/logout, profile, password).
- Database: MySQL (migrations + seeders; 3NF schema, PK/FK/UQ/enum
  constraints enforced at DB level).
- Frontend: Blade templates, Tailwind CSS 3, Alpine.js, Vite 8 build
  (run "npm run build"; assets served from public/build).
- All catalog/cart/order data is dynamic (database-driven, not
  hard-coded).

------------------------------------------------------------------------
DYNAMIC BEHAVIOR (Rubric Criterion 3)
------------------------------------------------------------------------
- All catalog data (products, categories, brands) is stored in and
  retrieved from the database, not hard-coded.
- Any product/category/brand created or edited by the admin immediately
  appears on the storefront.
- Product stock and variant stock affect availability shown to customers.
- Orders placed by customers appear in the admin orders list for
  processing, and status changes are reflected in the customer's
  "My Orders" and the public order-tracking page.
